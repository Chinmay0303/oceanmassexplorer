OCEAN WATER MASS EXPLORER - CODE MAP (state of repo: single commit "first commit")
=================================================================================
Legend: [P#] = proposal feature number (1-8), [N1] = novelty (fibers + regions in one renderer).
Status:  DONE / PARTIAL / MISSING.  Line numbers are approximate.

Stack: vanilla JS (ES modules) + WebGL2 + Canvas2D, Vite 7 build, Simple.css. No framework, no tests.
Rendering = one full-screen triangle + a single fragment shader that ray-marches a 3D texture.

SUGGESTED IMPROVEMENTS (priority order)
---------------------------------------------------------------------------------
 A. Fiber-surface quality (6.10/6.11): sign-change test on fixed 320 steps can miss thin sheets
    or leave holes (band limit uBand*8); refine with a bisection/secant step, adaptive step near
    the surface, or finer SDF. Compare against the fiber-surface paper's method.
 B. Real multidimensional TF (6.8): currently one flat colour per rectangle. Add per-rectangle
    opacity, soft (feathered) edges, and optionally a gradient-magnitude/lit volume shading.
 C. Complete P2: editable 1D TF (colour + opacity control points) with a legend / colour bar.
 D. T-S panel editing (5.5-5.7): select/move/resize/delete a single rectangle, edit curve points,
    hover readout of T, S and volume, undo/redo; named water-mass presets.
 E. Linked views: click a point in the 3D view -> show its (T,S) on the diagram (brushing both ways).
 F. Performance: empty-space skipping (min/max brick texture), cache uniform locations (3.3),
    optional quality slider for STEPS; drop mask channel / use R8 where possible.
 G. Data size & robustness: 33 MB uncompressed bins in git (store as 8-bit or gzip, or fetch from release);
    error handling for fetch/WebGL failures; version field in saved configs; lon seam at +-180.
 H. Geographic context: coastline/continent overlay, lat/lon/depth labels and axes, non-linear
    depth option (true metres vs level index).
 I. Code structure: split main.js into camera.js / gl.js / controls.js / config.js; add unit tests for
    prep.py ranges and config round-trip; remove stale doc references; add README screenshots + WOA23 citation.
 J. Evaluation material for the course: a few documented case studies (e.g. Mediterranean outflow,
    Antarctic Bottom Water) with saved configs, plus frame-time measurements.
