1. DATA PIPELINE (offline, Python)                                         [Dataset]
---------------------------------------------------------------------------------
 1.1 tools/download.py       fetches 39 WOA23 NetCDF files (t, s, o x annual + 12 months, span decav71A0 = 1971-2000, 1 deg) from NCEI.
 1.2 tools/prep.py           reads t_an / s_an / o_an; global value range per field over all files; fills land / below-seafloor / missing
                             cells with the nearest valid value (per field); writes uint16 planar [field][depth][lat][lon] plus a mask.
     read() L43, fill_nearest() L50, quantise() L55, main() L59: pass 1 = checks + ranges, pass 2 = writes.
 1.3 Output public/data/woa23/: meta.json (grid, depth axes, ranges, datasets, step labels, stats), annual/00.bin + .mask.bin,
     monthly/01..12.bin + .mask.bin. Annual = 102 levels (0-5500 m), monthly = 57 levels (0-1500 m, the first 57 annual levels).
     mask bit0 = ocean (T and S valid), bit1 = oxygen valid.
 1.4 tools/gen_colormaps.py  samples cmocean / matplotlib maps into src/colormap-stops.js (see Part 11).
 Contract: values are u / 65535 over meta.ranges[field] (T -3..36, S 4..44, O2 0..722).

COVERAGE AUDIT
---------------------------------------------------------------------------------
 Checked against the code of this version: every function and event listener in main.js, ts.js, selections-ui.js, data.js, legend.js, colormaps.js, theme.js,
 every uniform and helper in shaders.js, every id in index.html, the tools scripts, and the project files. Not mapped on purpose: src/simple.css (vendored),
 package-lock.json (generated), src/colormap-stops.js content (generated), public/data bins (generated).
 Data / format contracts used across files:
   volume texture   r = T, g = S, b = O2 (normalised 0-1 over meta.ranges), a = ocean (mask bit0)
   selection item   { id, kind, pair, n, name, color [r,g,b], visible, style, rect: s0 s1 t0 t1 | curve: points [[x,y]...] } in normalised diagram coordinates
   save file        { controls{...}, camera, pair, selections[...], data{dataset, step} }
   limits           8 rectangles, 4 curves (64 points each), 3 diagrams, 640 march steps max
 Known gaps (also in log.md / ROADMAP.txt): no cross-diagram AND combination, no editable 1D opacity curve, no seasonal dataset, no adaptive step size / empty-space
 skipping, GPU memory ~0.4 GB in monthly mode, picks the ocean surface only, no automated tests, nothing measured on a real GPU.
